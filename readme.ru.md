# Активные вызовы — модуль для MikoPBX

_Read this in other languages:_ [English](README.md), [Русский](readme.ru.md).

## Описание

Дополнительный модуль для MikoPBX, распространяется на платной основе. Предназначен для мониторинга текущих разговоров и работы супервизора с активными вызовами.

Официальная документация: [Активные вызовы](https://docs.mikopbx.com/mikopbx/modules/miko/aktivnye-vyzovy)

## Основные возможности

- Отображение всех активных вызовов
- Действия над вызовом: Подслушать, Шепнуть, Присоединиться, Завершить
- Отображение состояния выбранной очереди (ожидающие вызовы и агенты)
- Многопользовательский режим, совместимость с модулем «Управление доступом в систему»

## Интерфейс и использование

### Настройка текущего сотрудника
- При ограниченных правах поля «Сотрудник» и «Внутренний номер» заполняются автоматически.
- Под правами администратора можно выбрать сотрудника кликом по полю «Имя пользователя».
- Действия супервизора («Подключиться к разговору») выполняются от имени выбранного сотрудника.

### Отображаемая очередь
- Левая колонка: «вызовы в ожидании» — номер звонящего и время ожидания. Клик по заголовку — выбор другой очереди.
- Правая колонка: состояние сотрудников очереди с данными: «Внутренний номер», «Имя», «Собеседник». Статусы подсвечиваются цветом.

### Все активные звонки
- Каждая строка — один вызов, цветом подсвечивается статус.
- Колонки: «Начало» (ч:м:с), «Кто», «Кому», «Ожидание» (ч:м:с), «Разговор» (ч:м:с).

### Действия с вызовом
- «Завершить» — завершает выбранный разговор.
- «Подслушать» — звонок с внутреннего номера сотрудника, подключение без возможности быть услышанным.
- «Шепнуть» — подключение с возможностью подсказывать коллеге, клиент не слышит.
- «Присоединиться» — полноценное участие в разговоре.

## Установка
1. Установите модуль через веб-интерфейс MikoPBX (Маркетплейс модулей → Установить новый модуль).
2. Активируйте лицензию (если требуется).
3. Откройте модуль «Активные вызовы» и при необходимости выберите сотрудника и очередь.
